# MacChanger (Qt Tool)
[Read in English](README.md)

Кроссплатформенное (Linux-ориентированное) графическое приложение на C++/Qt6 для быстрого изменения MAC-адресов сетевых интерфейсов, управления профилями MAC-адресов и многопоточной диагностики сети.

## Основные возможности

* **Менеджер сетевых интерфейсов:** автоматическое обнаружение активных интерфейсов в системе (исключая `lo`).
* **Управление профилями MAC:** чтение и сохранение кастомных алиасов для MAC-адресов через конфигурационные INI-файлы.
* **Гибкая смена адреса:** поддержка ручного ввода MAC-адреса с валидацией маски, выбор из преднастроенных профилей или быстрый сброс на "родной" заводской адрес.
* **Безопасное выполнение:** применение настроек в системе через `pkexec` с запросом root-привилегий только в момент изменения.
* **Интеграция с системным треем:** автоматическая проверка поддержки трея системой. Сворачивание приложения в трей при закрытии, контекстное меню для быстрого разворачивания, перезапуска или выхода.
* **Многопоточный диагностический утилит (Ping):** поддержка динамических вкладок (№1, №2...) для одновременного пинга нескольких узлов. Каждая вкладка полностью автономна, сама определяет текущий активный шлюз системы (default via) и управляет изолированным процессом пинга.
* **Полное управление с клавиатуры:** поддержка продвинутых хоткеев для быстрой работы без мыши.

## Горячие клавиши (Shortcuts)
* `Ctrl + Q` — Полное закрытие приложения (выгрузка из памяти).
* `Ctrl + W` — Закрыть окно (свернуть в системный трей).
* `Ctrl + T` — Создать новую вкладку сетевого мониторинга (работает на вкладке Ping).
* `Ctrl + Shift + W` — Закрыть текущую активную вкладку мониторинга.
* `Ctrl + R` — Перечитать конфигурационный файл с диска (работает на вкладке MacChanger).
* `Ctrl + Shift + R` — Горячий перезапуск всего приложения.
* `Ctrl + Enter` — Применить MAC-адрес или запустить/остановить пинг (в зависимости от активной вкладки).

## Архитектурная структура проекта
Проект разделен на изолированные модули по канонам чистого ООП:

* `CMakeLists.txt` — Главный файл конфигурации современной сборки CMake.
* `main.cpp` — Точка входа в приложение, обработка флагов CLI и инициализация главного виджета.
* `macchanger_widget.h / .cpp / .ui` — Логика главного окна, управление профилями, интерфейсами, треем и хоткеями.
* `ping_tab.h / .cpp / .ui` — Автономный изолированный виджет вкладки пинга со своим процессом `QProcess` и автоопределением шлюза.
* `resources.qrc` — Файл ресурсов Qt, компилирующий дефолтный конфигурационный файл внутрь исполняемого файла.
* `default_config.ini` — Базовый конфигурационный файл со структурой интерфейсов и алиасов.

## Конфигурация (INI)
При первом запуске приложение создает физический файл конфигурации по пути `~/.config/macchanger/address_aliases.ini`. Если файл пуст, в него автоматически импортируются настройки по умолчанию из ресурсов приложения:

* `[DEFAULTS]` — Хранит интерфейс по умолчанию и оригинальные (родные) MAC-адреса для быстрого восстановления.
* `[MAC_ALIASES]` — Пользовательские именованные профили для удобного переключения (например, "Home_Router", "Work_AP").

## Сборка и запуск
### Требования к системе

* Компилятор с поддержкой стандарта **C++17** (GCC / Clang).
* Система сборки **CMake** (минимальная версия 3.16).
* Установленный фреймворк **Qt 6** (компоненты Core, Gui, Widgets).
* Для работы утилит внутри системы требуют установленные пакеты: `iproute2` (команда ip), `iputils-ping` (ping) и `policykit-1` (pkexec).

### Инструкция по сборке

1. Создайте папку для сборки и перейдите в неё:
   ```sh
   mkdir build && cd build
   ```
2. Сгенерируйте файлы конфигурации сборки через CMake:
   ```sh
   cmake ..
   ```
3. Скомпилируйте проект:
   ```sh
   make
   ```
   
### Флаги запуска
Приложение поддерживает запуск в скрытом режиме напрямую в системный трей:
```sh
./MacChanger --tray
```
*Примечание: Если в системе отсутствует или недоступен системный трей, флаг `--tray` будет проигнорирован, и приложение откроется в обычном оконном режиме.*

### Создание пакетов установки

#### 1. Сборка .deb пакета (Для Debian / LMDE / Ubuntu)
Проект использует встроенный в CMake модуль **CPack** для автоматической упаковки приложения.
Чтобы собрать нативный `.deb` пакет, который сам пропишет зависимости и добавит ярлык в меню Cinnamon:
```sh
mkdir -p build && cd build
cmake ..
make
make package
```
После этого в папке `build` появится готовый файл `macchanger-toolkit-<version>-amd64.deb`.

#### 2. Сборка пакета для Arch Linux
В корне репозитория подготовлен скрипт локального `PKGBUILD`. Чтобы скомпилировать и чисто установить нативный пакет Арча силами `pacman` напрямую из локальной папки:
```sh
makepkg -si
```

## Важное примечание по безопасности
Для изменения MAC-адреса приложение выполняет системные команды (`ip link set dev ...`). При нажатии на кнопку "Apply" операционная система вызовет графическое окно polkit (`pkexec`) для авторизации пользователя с правами sudo/root. Без ввода корректного пароля администратора MAC-адрес изменен не будет.

Также есть возможность включить кэширование пароля (на 5 минут) для pkexec, чтобы не нужно было каждый раз вводить пароль (на свой страх и риск):
```sh
echo -e 'polkit.addRule(function(action, subject) {\n    if (action.id == "org.freedesktop.policykit.exec") {\n        return polkit.Result.AUTH_ADMIN_KEEP;\n    }\n});' | sudo tee /etc/polkit-1/rules.d/50-pkexec-global.rules
```
