## MacChanger (Qt Tool)
Кроссплатформенное (Linux-ориентированное) графическое приложение на C++/Qt для быстрого изменения MAC-адресов сетевых интерфейсов, управления профилями MAC-адресов и базовой диагностики сети.
## Основные возможности

* Менеджер сетевых интерфейсов: автоматическое обнаружение активных интерфейсов в системе (исключая lo).
* Управление профилями MAC: чтение и сохранение кастомных алиасов для MAC-адресов через конфигурационные INI-файлы.
* Гибкая смена адреса: поддержка ручного ввода MAC-адреса с валидацией маски, выбор из преднастроенных профилей или быстрый сброс на "родной" заводской адрес.
* Безопасное выполнение: применение настроек в системе через pkexec с запросом root-привилегий только в момент изменения.
* Интеграция с системным треем: сворачивание приложения в трей при закрытии, контекстное меню для быстрого разворачивания, перезапуска или выхода.
* Сетевой диагностический утилит: автоматическое определение IP-адреса шлюза (роутера) для выбранного интерфейса и встроенный инструмент ping с возможностью быстрой смены подсети.

## Архитектура проекта и файлы
Проект построен на базе Qt Core/Gui/Widgets и состоит из следующих файлов:

* MacChanger.pro: Файл конфигурации сборки qmake (требуется стандарт C++17).
* main.cpp: Содержит весь исходный код приложения, включая логику графического интерфейса MacChangerWidget и обработку аргументов командной строки.
* resources.qrc: Файл ресурсов Qt, компилирующий дефолтный конфигурационный файл внутрь исполняемого файла.
* default_config.ini: Файл конфигурации по умолчанию со структурой интерфейсов и алиасов.

## Конфигурация (INI)
При первом запуске приложение создает физический файл конфигурации по пути ~/.config/macchanger/address_aliases.ini. Если файл пуст, в него автоматически импортируются настройки по умолчанию из ресурсов приложения:

* [DEFAULTS]: Хранит интерфейс по умолчанию и оригинальные (родные) MAC-адреса для быстрого восстановления.
* [MAC_ALIASES]: Пользовательские именованные профили для удобного переключения (например, "Домашний_Роутер", "Рабочая_Точка").

## 📦 Сборка и запуск## Требования к системе

* Компилятор с поддержкой C++17 (GCC / Clang).
* Установленный фреймворк Qt 5 или Qt 6 (библиотеки core, gui, widgets).
* Для работы утилит внутри системы требуются установленные пакеты: iproute2 (команда ip), iputils-ping (ping) и policykit-1 (pkexec).

## Инструкция по сборке

   1. Сгенерируйте Makefile с помощью утилиты qmake:
   
   qmake MacChanger.pro
   
   2. Скомпилируйте проект:
   
   make
   
   
## Флаги запуска
Приложение поддерживает запуск в скрытом режиме напрямую в системный трей:

./MacChanger --tray

Примечание: Если в системе отсутствует или недоступен системный трей, флаг --tray будет проигнорирован, и приложение откроется в обычном оконном режиме.
------------------------------
## ⚠️ Важное примечание по безопасности
Для изменения MAC-адреса приложение выполняет системные команды (ip link set dev ...). При нажатии на кнопку "Применить изменения" операционная система вызовет графическое окно polkit (pkexec) для авторизации пользователя с правами sudo/root. Без ввода корректного пароля администратора MAC-адрес изменен не будет.
